# Ship RF Audit

Android Wi-Fi survey utility for authorized infrastructure checks. Records SSID, BSSID, signal strength and survey area, provides Starlink-name-match flags (not proof of Starlink equipment), supports CSV export, and does not monitor people's traffic.

The GitHub Actions workflow assembles a signed debug APK as a downloadable build artifact. The app cannot identify a specific person or detect Wi-Fi-disabled satellite equipment.

*Note: A debug APK is intended for testing. Only install on a phone you administer and after reviewing the repository code and APK source.*
