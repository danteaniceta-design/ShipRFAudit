CAPABILITIES

Practical wireless observations

The Android app reads nearby access points using Android's available Wi-Fi scan results. Use these findings as leads for your authorized IT investigation, not as proof against an individual.

⌁

Nearby Wi-Fi scanning

View SSIDs, BSSIDs, channels, frequencies, and signal strength in dBm on your Android phone.

⌕

Starlink name matches

Flags SSIDs containing “Starlink.” A renamed or disabled Wi-Fi network will not be reliably identified.

≡

Survey and export

Record the survey deck or area, save local observations, and export a CSV report for review.

BROWSER TOOL

Record observations on the web

Don't need to scan right now? This browser tool keeps manual survey notes on your device. No sign-in and no uploads.

GET STARTED

Install on Android in 3 steps

If ChatGPT's file links won't open, use this website in Chrome and download directly from GitHub.

1

Download the APK

Tap the green Download Android App button. If prompted, confirm the download in Chrome.

2

Find the file

Open Files or My Files → Downloads and tap ShipRFAudit.apk.

3

Install and scan

Install if your device policy permits, enable Wi-Fi and Location, grant scan permissions, then start a survey.
